# 대기업집단 경영진 지도 (AI ROASTING 경영진 분석)

공정위 2026년 공시대상기업집단 102개 그룹의 공시 회사 임원(등기 + 미등기)을 DART 정기보고서 원문에서 추출해 일관된 기준으로 정리하고, 2018년부터 2026년 6월까지 이어 붙여 선임·승진·이탈을 계산하고, 담당업무·학력·출신을 분류해 그룹끼리 비교하는 프로젝트다. 기획은 [CONCEPT.md](CONCEPT.md), 분류 기준은 [taxonomy.md](taxonomy.md).

- 분류: Prototype (Core Asset 후보)
- 현재 단계: 102개 그룹 전체 + 2026 반기 + 분류 v2 + 사이트 5차, 디자인 개편(에디토리얼 리포트) (2026-11-07)
- 사이트: `docs/index.html` (GitHub Pages에 그대로 올릴 수 있는 정적 사이트), 공개 주소 https://airoasting.github.io/dart-analysis/

## 실행 방법

준비: 환경변수 `DART_API_KEY`. 파이썬 표준 라이브러리만 쓴다. OpenDART 호출 간격은 0.5초 이상(초당 수 건이면 IP가 약 1시간 차단된다). 이미 받은 것은 다시 받지 않는다.

```bash
python3 -I pipeline/01_groups.py --top 102 --fill-unlisted
```

```bash
python3 -I pipeline/02_fetch.py data/companies.csv --years 2018-2025 --workers 3 && python3 -I pipeline/02_fetch.py data/companies.csv --years 2026 --period H1 --workers 3
```

```bash
for y in 2018 2019 2020 2021 2022 2023 2024 2025 2026; do python3 -I pipeline/03_parse.py --year $y; done
```

```bash
python3 -I pipeline/05_link.py --years 2018-2026 && python3 -I pipeline/06_group_report.py --year 2026 --flow-end 2025 --pay-year 2025 && python3 -I pipeline/08_classify.py && python3 -I pipeline/09_assets.py --year 2025 && python3 -I pipeline/10_pay_staff.py --fetch && python3 -I pipeline/11_audit.py --fetch && python3 -I pipeline/07_site_data.py
```

## 알려진 한계

- 비상장 계열사 임원은 없다(두나무 제외). '이탈'에는 퇴임과 비상장 계열사 이동이 섞여 있다.
- 같은 사람 판정은 이름 + 출생연월 + 그룹. 다른 그룹으로 옮긴 사람은 경력 문구의 '타 그룹 출신' 태그로만 보인다.
- 2018년이나 회사가 처음 보인 해에 이미 임원이던 사람의 취임 연도는 모른다.
- 미등기 임원 경력은 대개 직전 보직 한 줄이라 신규 임원의 약 40%는 출신을 판단할 수 없다.
- 분류 v2 수치는 규칙을 고친 표본에서 잰 값이라 낙관적이다. 새 표본 재검수가 필요하다.
- 원문 링크는 보고서 첫 화면으로 간다(섹션 직접 링크는 아직).
- 개인별 보수는 5억 원 이상이거나 회사 상위 5명일 때만 공시된다. 공시 없는 해를 0으로 읽으면 안 된다. 퇴임 연도에는 퇴직금이 들어가 크게 뛴다.
- 등기임원 평균 보수에는 사외이사·감사위원이 함께 들어가 사내이사만의 평균보다 낮다. 직원 급여는 회사가 원·천 원·백만 원 중 무엇으로 적었는지 값 크기로 추정해 맞췄다.
- 그룹 직원 수 합계는 공시 회사가 바뀌면 함께 움직인다. 같은 회사 기준선(9개 시점 모두 공시)과 증감률(2020년 말·2026년 6월 말 모두 공시)을 따로 둔다.
- 외부 공개 전 법률 검토가 필요하다. 공시 정보라도 개인 단위로 시계열을 모은 것이고, 이사회 법정 요건(상법 제542조의8, 자본시장법 제165조의20) 미충족 회사 이름을 공시 명단 기준으로 표시한다. 정정 요청 창구(운영 주체·연락처)는 아직 정하지 않았다(`07_site_data.py`의 `SITE_OWNER`, `SITE_CONTACT`).
- 외부 경력 비율이 0%나 100%인 그룹(현재 호반)은 '검수 필요'로 순위에서 뺐다. 원문 검수 후 `taxonomy.md`에 결과를 남긴다.

## 데이터 다루는 원칙
