# 50대 그룹 경영진 지도 (EXEC ATLAS 50)

공정위 2026년 지정 상위 50개 그룹의 공시 회사 임원(등기 + 미등기)을 DART 정기보고서 원문에서 뽑아 같은 기준으로 정리하고, 2018년부터 2026년 6월까지 이어 붙여 선임·승진·이탈을 계산하고, 담당업무·학력·출신을 분류해 그룹끼리 비교하는 프로젝트다. 기획은 [CONCEPT.md](CONCEPT.md), 분류 기준은 [taxonomy.md](taxonomy.md).

- 분류: Prototype (Core Asset 후보)
- 현재 단계: 50대 그룹 + 2026 반기 + 분류 v2 + 사이트 5차(멀티 페르소나 4라운드 평가 반영, 4차 평균 8.9) (2026-10-31)
- 사이트: `docs/index.html` (GitHub Pages에 그대로 올릴 수 있는 정적 사이트), 아티팩트 https://claude.ai/artifact/RPyEYUq7rpnEynWfkrdjro (비공개)

## 범위

| 항목 | 내용 |
|---|---|
| 그룹 | 공정위 2026년 공시대상기업집단 지정(2026-04-30 보도자료 별첨 2) 1~50위. 원본 `data/source/ftc_2026/` |
| 회사 | 50개 그룹 소속회사(별첨 5) 중 상장사 266곳 + 비상장이지만 사업보고서를 내는 두나무 = 267곳. 법인등록번호로 매칭. 위탁관리 리츠 5곳 제외 |
| 자료 없는 그룹 | 쿠팡, 부영, 한국지엠: 소속회사가 사업보고서를 내지 않아 임원 명단 공시가 없다(감사보고서·기업집단 현황공시만). 사이트에는 사유와 함께 표시 |
| 기간 | 2018~2025 사업보고서(12월 말) + 2026 반기보고서(6월 말). 단면 지표는 2026.6.30, 연간 흐름(신규율·이탈률)은 2020~2025 평균, 보수는 2025 연간 |
| 규모 | 사람-연도-회사 92,735행, 고유 인물 23,225명. 2026.6.30 경영진 9,533명(그룹 안 겸직 1명) |

## 실행 방법

준비: 환경변수 `DART_API_KEY`. 파이썬 표준 라이브러리만 쓴다. OpenDART 호출 간격은 0.5초 이상(초당 수 건이면 IP가 약 1시간 차단된다). 이미 받은 것은 다시 받지 않는다.

```bash
python3 -I pipeline/01_groups.py --top 50 --fill-unlisted
```

```bash
python3 -I pipeline/02_fetch.py data/companies.csv --years 2018-2025 --workers 3 && python3 -I pipeline/02_fetch.py data/companies.csv --years 2026 --period H1 --workers 3
```

```bash
for y in 2018 2019 2020 2021 2022 2023 2024 2025 2026; do python3 -I pipeline/03_parse.py --year $y; done
```

```bash
python3 -I pipeline/05_link.py --years 2018-2026 && python3 -I pipeline/06_group_report.py --year 2026 --flow-end 2025 --pay-year 2025 && python3 -I pipeline/08_classify.py && python3 -I pipeline/09_assets.py --year 2025 && python3 -I pipeline/07_site_data.py
```

| 단계 | 하는 일 | 결과 |
|---|---|---|

## 알려진 한계

- 비상장 계열사 임원은 없다(두나무 제외). '이탈'에는 퇴임과 비상장 계열사 이동이 섞여 있다.
- 같은 사람 판정은 이름 + 출생연월 + 그룹. 다른 그룹으로 옮긴 사람은 경력 문구의 '타 그룹 출신' 태그로만 보인다.
- 2018년이나 회사가 처음 보인 해에 이미 임원이던 사람의 취임 연도는 모른다.
- 미등기 임원 경력은 대개 직전 보직 한 줄이라 신규 임원의 약 40%는 출신을 판단할 수 없다.
- 분류 v2 수치는 규칙을 고친 표본에서 잰 값이라 낙관적이다. 새 표본 재검수가 필요하다.
- 원문 링크는 보고서 첫 화면으로 간다(섹션 직접 링크는 아직). 등기임원 개인별 보수(5억 이상)는 아직 없다.
- 외부 공개 전 법률 검토가 필요하다. 공시 정보라도 개인 단위로 시계열을 모은 것이고, 이사회 법정 요건(상법 제542조의8, 자본시장법 제165조의20) 미충족 회사 이름을 공시 명단 기준으로 표시한다. 정정 요청 창구(운영 주체·연락처)는 아직 정하지 않았다(`07_site_data.py`의 `SITE_OWNER`, `SITE_CONTACT`).
- 외부 경력 비율이 0%나 100%인 그룹(현재 호반)은 '검수 필요'로 순위에서 뺐다. 원문 검수 후 `taxonomy.md`에 결과를 남긴다.

## 데이터 다루는 원칙

- 공시 원문에 있는 필드만 쓴다. 뉴스나 SNS 정보를 붙이지 않는다.
- 모든 행에 DART 원문 링크(`source_url`)를 남긴다.
- `data/raw/`, `data/source/`는 내려받은 원문이다. 손으로 고치지 않는다.
