# 디자인 개편안: 에디토리얼 리포트

작성: 2026-11-04. 방법: 5-Color Harness. RED·SILVER·BLUE·GOLD가 각자 테마 후보 3개를 판정해 하나씩 추천했고(`proposal_*.md`), BLACK이 갈린 의견을 정리했습니다. 기준 캡처는 `now_*.png`입니다.

## 1. 결론

**테마: 에디토리얼 리포트.** 경제지 데이터면(FT, The Economist)의 지면 문법을 기본으로 삼고, 컨설팅 보고서의 블록 규격(결론 제목, 정의, 본체, 출처)을 더합니다.

| 비평가 | 추천 | 핵심 이유 |
|---|---|---|
| RED | 에디토리얼 + 스위스 격자 | 상자 대신 괘선으로 위계를 만들 수 있습니다 |
| SILVER | 에디토리얼 데이터 저널리즘 (FT·Economist 차트, Datawrapper 표) | 금융·지배구조 데이터 제품의 현장 표준입니다 |
| BLUE | 에디토리얼(경제지 데이터면형) | 첫 5초에 결론이 보이고, 덜 차갑습니다 |
| GOLD | 리포트형(컨설팅 보고서 풍) | 화면이 아니라 '남의 보고서에 붙는 블록'이 산출물입니다 |

**뺀 후보와 이유**
- 뉴모피즘·글래스모피즘: 그림자와 반투명이 표 경계를 흐리고 대비가 낮아집니다. 인쇄하면 효과가 사라집니다.
- 벤토 그리드: 제품 홍보 페이지처럼 보이고, A4 한 장에 맞지 않습니다.
- 블룸버그 터미널형: HR·지배구조 담당자에게 진입 장벽이 높고, 인쇄와 맞지 않습니다.
- 스위스 스타일 단독: 여백이 커서 A4에 담기는 정보가 줄고, 지금보다 더 차갑게 보입니다.

## 2. 지금 화면이 별로로 보이는 이유 (네 명 공통)

1. 모든 블록이 같은 흰 카드, 같은 회색 테두리, 같은 무게입니다. 먼저 볼 곳이 없습니다.
2. 결론이 제목이 아니라 회색 작은 본문에 묻혀 있습니다. KPI 숫자(26px)도 아래 설명 4~5줄에 묻힙니다.
3. 색에 정해진 역할이 없습니다. 남색, 회청 막대, 파랑·초록 사건색, 보라·황토 범주색이 화면마다 따로 놀아서 '내 그룹'과 '기준선'이 색으로 구분되지 않습니다.
4. 50행 표가 모두 같은 무게이고, '표본 작음'이 칸마다 반복돼 잡음이 큽니다.

## 3. 갈린 의견과 정리

| 쟁점 | 의견 | 정리 |
|---|---|---|
| 바탕색 | SILVER·BLUE·RED: 따뜻한 종이색. GOLD: 흰 바탕(사내 템플릿에 붙였을 때 남의 기사처럼 보임) | 화면은 아주 옅은 종이색 #FAF8F5(FT 연분홍이 아님), 인쇄는 순백 #FFFFFF |
| 색 수 | SILVER: 범주색 6개. GOLD: 남색 1색 + 회색만 | 비교 화면은 남색과 회색만 씁니다. 범주색 6개는 범주 자체가 정보인 차트(사외이사 출신, 맡은 일)에만 씁니다 |
| 내 그룹 표시 | RED: 빨강. BLUE: 금색. SILVER: 왼쪽 강조선 | 행은 옅은 노랑 바탕 #FFF3CC와 왼쪽 3px 남색 선. 빨강은 경고·감소에만 남겨 둡니다 |
| 긴 표 | BLUE: 상위 10개와 내 그룹만 먼저. 나머지: 전체 + 5행 구분선 | 기준 띠 + 상위 10 + 내 그룹을 먼저 보이고 '41개 그룹 모두 보기'로 펼칩니다. 표본 작음·공시 없음 그룹은 표 아래 '비교에서 뺀 그룹'으로 모읍니다 |

## 4. 적용 규칙

**색 토큰 (라이트 / 다크)**
- 바탕 #FAF8F5 / #141518, 잉크 #1A1A1A / #ECE9E3, 보조 #4A4A4A, 흐린 글자 #6B6B6B / #A29D95, 구분선 #E2DDD4 / #2E2F33
- 역할: 선택·내 그룹 #1D4E89 / #7FA8E0, 50대 전체 기준선 #8C8780 점선, 나머지 그룹 #CFCAC2, 감소·경고 #B3261E, 증가 #1E7A4F
- 범주색(이 순서로 고정): #1D4E89, #D17A22, #2E8B7A, #8E5BA8, #B8463A, #7A8B3D, 그 밖은 '기타' #BDB8B0

**타이포 (Pretendard 유지)**
- 4단: 화면 제목 30px/700, 섹션 제목 20px/700, 본문 13.5px, 각주 12px
- KPI 숫자 40px/700 tabular, 단위 16px 흐린 글자, 증감 한 줄 13px(▲▼)

**레이아웃과 블록**
- 카드 테두리와 둥근 상자를 없앱니다. 섹션은 위쪽 2px 잉크 괘선과 제목으로 나눕니다. 표 안만 흰 표면을 씁니다.
- 첫 화면 위쪽: 큰 제목, 숫자 4개를 상자 없이 한 줄 띠로 놓습니다. 안내 상자와 중복된 그룹 선택기는 '내 그룹과 비교하기' 하나로 합칩니다.
- 관찰 카드 4개는 번호 붙은 '주요 발견'으로 바꾸고, 핵심 숫자만 강조색으로 칠합니다.
- 모든 차트·표 블록은 같은 규격입니다. 결론 문장 제목, 단위·기준일 부제, 본체, 맨 아래 출처 한 줄("자료: DART 사업·반기보고서, 2026.6.30 기준"). 블록 하나만 캡처해도 근거가 남게 합니다.

**표**
- 세로선은 구획 경계 한 줄만 남깁니다. 머리 행은 고정하고, 그 아래에 1.5px 잉크 선을 긋습니다. 행 높이는 34px이고, 5행마다 조금 진한 구분선을 넣습니다.
- 기준 띠(전체·중앙값·상위 10)는 위아래 잉크 선으로 묶습니다. 미니 막대는 높이 6px, 폭 64px로 하고 50대 전체 값에 눈금을 그립니다.

**차트**
- y축 선을 없애고 가로 격자선만 남깁니다. 0 기준선만 1px 잉크로 긋습니다.
- 범례 대신 선 끝에 직접 라벨을 답니다. 선택 그룹만 강조색, 나머지는 회색입니다.
- 흑백 인쇄에서도 구분되도록 선 모양(실선, 점선)을 함께 씁니다.

**보고서 한 장**
- 결론 헤드라인, 핵심 메시지 3개, 비교표, 차트 2개, 정의·출처 2줄 순서로 놓습니다. 정의 문단을 줄여 A4 끝에서 잘리지 않게 합니다.

## 5. 진행 순서

1. 색 토큰과 카드 걷기, 첫 화면 위쪽 띠만 먼저 바꿉니다. 그다음 `now_home.png`와 전후를 비교합니다.
2. 비교표 규칙(기준 띠, 펼치기, 비교에서 뺀 그룹)을 적용합니다.
3. 차트 규칙과 블록 규격(결론 제목, 출처 줄)을 그룹 화면과 보고서 한 장에 적용합니다. A4 1쪽 인쇄를 다시 실측합니다.
4. 네 비평가가 전후 캡처로 재채점합니다.

## 참고: 모바일 넘침 지적

세 비평가가 `now_mobile.png`에서 KPI와 차트가 오른쪽으로 잘린다고 했습니다. 이 캡처는 헤드리스 Chrome이 휴대폰 화면을 흉내 내지 않고 찍은 것입니다. 실제 휴대폰 크기(375px)로 확인했을 때는 가로 넘침이 없었습니다. 개편 후에는 휴대폰 크기로 다시 캡처해 확인합니다.
