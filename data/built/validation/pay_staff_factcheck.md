# 직원·보수 데이터 팩트 검증 (2026-11-14)

목적: `10_pay_staff.py`로 새로 넣은 직원 수·직원 급여·등기임원 보수·개인별 보수(5억 원 이상)·미등기 보수 연도별 값이 DART 원본과 같은지 확인한다.
방법: 결과를 보지 않은 검증자 셋(5-Color의 RED·SILVER·GOLD)이 무작위 표본을 OpenDART API 실시간 값과 공시 원문(document.xml의 단위 표기)에 직접 대조했다. 판정은 일치, 불일치, 확인 불가 세 가지만 쓴다.

## 남은 차이 (고치지 않고 공개)

- 직원 현황을 성별로만 합계한 대형사는 성별 값을 인원으로 가중해, 회사가 적은 전체 평균과 1% 안팎 다르다. 삼성전자 2025 157.1(공시 158), LG전자 2025 117.6(공시 117), 두나무 2021 386.7(공시 392.9), 삼성전자 2026 반기 근속 14.1(공시 14.0). API에 회사 전체 합계 행이 없어서 생긴다. 원문 표를 읽으면 없앨 수 있다.
- 해원에스티 2024 직원 1명, 급여 총액 2.39억 원은 원문 단위 표기대로이지만 값이 이상하다. 원문 그대로 둔다.
- 폰드그룹 2023은 분할 직후 며칠치라 1인 평균을 비웠다.

## 다시 돌리는 법

`python3 -I pipeline/10_pay_staff.py`가 `data/built/pay_staff_report.md`에 연도별 수집 수와 보정 건수를 남긴다. 보정 규칙과 사례는 `10_pay_staff.py`의 `unit_scale`, `indiv_amount`, `staff_row` 주석에 있다.
